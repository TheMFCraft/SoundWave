# SoundWave Website

Statische Seite für Netlify. Kein Build, kein Node.

## Hochladen

1. Bei [Netlify](https://app.netlify.com) einloggen.
2. **Add new site** → **Deploy manually**.
3. Den kompletten Inhalt dieses Ordners `website` ziehen (nicht den ganzen SoundWave-Ordner).
4. Nach dem Deploy die URL kopieren, z. B. `https://irgendwas.netlify.app`.
